# LinguaCafe 0.5.39

This release implements the mobile UI regression plan created after comparing the current Vue 3 / Vuetify 3 frontend with the pre-migration LinguaCafe code. It focuses on reusable layout fixes for cramped cards, sidebar controls, numeric pills, reader settings controls and mobile theme editor behavior.

## Fixed

- Improved dashboard daily goal card sizing so descriptions wrap naturally and actions remain separated at the bottom.
- Aligned the sidebar Language control with the other bottom controls and added safe bottom spacing for drawer append content.
- Hardened the import stepper layout for Vuetify 3 so connector lines stay away from labels and mobile headers wrap cleanly.
- Updated book summary and chapter word-count pills to fit larger comma-formatted numbers without clipping or ambiguous wrapping.
- Restyled chapter read-status chips so finished counts remain visible and theme-consistent.
- Reduced reader settings slider thumb size and increased slider row spacing so value bubbles do not collide with neighboring controls.
- Improved reader settings switch/help row behavior on mobile so labels, help icons and switches stay visually associated.
- Strengthened dark fullscreen reader toolbar contrast while preserving the existing 44px toolbar width baseline.
- Hardened the user settings text-theme editor with responsive setting rows, checkbox wrapping and mobile color-table overflow handling.

## Changed

- Added a trackable mobile UI regression root-cause plan under `release-notes/mobile-ui-regression-plan.md`.
- Kept fixes scoped to shared component/layout styles instead of viewport-specific screenshot offsets.

## Docker image

Published images are built by GitHub Actions and pushed to GitHub Container Registry:

- `ghcr.io/kscop-n1/linguacafe-webserver:v0.5.39`
- `ghcr.io/kscop-n1/linguacafe-python-service:v0.5.39`
- `ghcr.io/kscop-n1/linguacafe-webserver:latest`
- `ghcr.io/kscop-n1/linguacafe-python-service:latest`

To update a Docker Compose install that already uses these GHCR images:

```bash
cd /home/serhii/docker/linguacafe
docker compose pull
docker compose up -d
```

If the compose file pins a version tag, update the image tags to `v0.5.39` first, then run the commands above.
