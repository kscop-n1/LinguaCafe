# LinguaCafe 0.5.37

This release fixes vocabulary/book filtering regressions, the user manual 404 on direct manual routes, and a broad set of visual regressions left after the Vue/Vuetify migration.

## Fixed

- Fixed vocabulary filtering by book after the migration by using migrated `unique_word_ids` when available instead of matching only by word text.
- Fixed manual page loading when no manual file name is present, so `/user-manual` no longer requests an empty `/manual/get-manual-file` URL.
- Fixed chapter list requests for book ids after the migration validation changes.
- Fixed daily goal cards so descriptions wrap naturally and action buttons stay aligned.
- Fixed bottom sidebar spacing and language selector alignment.
- Fixed import dialog stepper labels so progress lines no longer cross label text.
- Fixed book summary and chapter word-count pills so multi-digit values are not clipped or split.
- Fixed chapter read-status chips so finished counts remain visible and aligned.
- Fixed reader settings sliders, switches and help icons so controls no longer overlap or disappear in light/dark themes.
- Fixed reader fullscreen toolbar contrast in dark theme.
- Fixed user settings theme text styling layout so slider values, labels and checkboxes are readable on desktop and mobile.

## Changed

- Added a PHP regression test for book-filtered vocabulary results using `unique_word_ids`.
- Added a reusable PHP test command: `npm run test:php`.
- Expanded migration/static test coverage around chapter validation and manual route handling.

## Docker image

Published images are built by GitHub Actions and pushed to GitHub Container Registry:

- `ghcr.io/kscop-n1/linguacafe-webserver:v0.5.37`
- `ghcr.io/kscop-n1/linguacafe-python-service:v0.5.37`
- `ghcr.io/kscop-n1/linguacafe-webserver:latest`
- `ghcr.io/kscop-n1/linguacafe-python-service:latest`

To update a Docker Compose install that already uses these GHCR images:

```bash
cd /home/serhii/docker/linguacafe
docker compose pull
docker compose up -d
```

If the compose file pins a version tag, update the image tags to `v0.5.37` first, then run the commands above.
