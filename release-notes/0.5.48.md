# LinguaCafe 0.5.48

This release fixes the remaining UI, vocabulary parser, modal layout, and control consistency regressions reported in the latest screenshot batch.

## Fixed

- Hardened vocabulary token validation so punctuation fragments, dice/stat notation, arithmetic-like tokens, numeric/unit mixtures, and incomplete symbol tokens are no longer imported as vocabulary.
- Extended existing invalid-token cleanup coverage for examples such as `-fis`, `-m`, `/12*mp`, `1+db`, `1d10+db`, `1d3-1`, `1d4+poison`, and `1d6/` while preserving valid words, contractions, Unicode words, and lexical hyphenated words.
- Fixed Vocabulary CSV import so it uses the same token classifier as reader/import parsing and does not recreate invalid vocabulary rows.
- Restored compact shared table action buttons across Admin Users, Dictionaries, Fonts, and Vocabulary tables.
- Restored circular Reader and Review vertical toolbar buttons with centered icons and stable dimensions.
- Increased shared dialog body sizing for admin, vocabulary, import, and reader settings modals so desktop layouts no longer show unnecessary internal scrollbars.
- Fixed unreadable Word/Phrase edit modal chips by using visible primary chip text and current Vuetify icon sizing.
- Replaced broken symbolic Vocabulary sort menu entries with readable ascending/descending labels.
- Updated the Vocabulary import user manual link to the current import documentation route.
- Fixed Calendar popover action icon contrast so edit/delete buttons are visible in light and dark themes.
- Aligned Sidebar bottom controls so Hide, Theme, and Language icons follow the same icon/label layout as main sidebar items.
- Tightened Reader Settings slider, help icon, and switch-row alignment to prevent overlapping controls.

## Added

## Existing DB Cleanup Instructions

The parser/import changes prevent new invalid tokens from being created. Existing rows already present in a database should be reviewed with the cleanup command after updating:

```bash
cd /home/serhii/docker/linguacafe
docker compose pull
docker compose up -d
docker exec linguacafe-webserver php artisan linguacafe:cleanup-non-word-vocabulary
```

Review the dry-run JSON summary before applying. To clean one user first:

```bash
docker exec linguacafe-webserver php artisan linguacafe:cleanup-non-word-vocabulary --user-id=1
docker exec linguacafe-webserver php artisan linguacafe:cleanup-non-word-vocabulary --user-id=1 --apply
```

To clean all users/languages after reviewing dry-run output:

```bash
docker exec linguacafe-webserver php artisan linguacafe:cleanup-non-word-vocabulary --apply
```

The command does not hard-delete vocabulary rows. With `--apply`, invalid tokens are marked ignored, review scheduling is cleared, affected chapter unique-word metadata is repaired, and affected book/chapter word counts are recalculated.

## Docker image

Published images are built by GitHub Actions and pushed to GitHub Container Registry:

- `ghcr.io/kscop-n1/linguacafe-webserver:v0.5.48`
- `ghcr.io/kscop-n1/linguacafe-python-service:v0.5.48`
- `ghcr.io/kscop-n1/linguacafe-webserver:latest`
- `ghcr.io/kscop-n1/linguacafe-python-service:latest`

To update a Docker Compose install that already uses these GHCR images:

```bash
cd /home/serhii/docker/linguacafe
docker compose pull
docker compose up -d
docker exec linguacafe-webserver php artisan migrate --force
```

If the compose file pins a version tag, update the image tags to `v0.5.48` first, then run the commands above.
