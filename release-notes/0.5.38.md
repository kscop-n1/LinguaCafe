# LinguaCafe 0.5.38

This release restores the pre-migration LinguaCafe visual theme colors in the Vue 3 / Vuetify 3 frontend and tightens the remaining UI regressions found during post-migration review.

## Fixed

- Restored the old warm LinguaCafe light and dark theme palettes from the pre-migration app instead of the temporary blue/slate palette.
- Fixed Vuetify 3 menu, dropdown, popup, modal, form, hover, focus, active, icon and mobile bottom navigation colors so they map to the old visual language using the current theme variables and selectors.
- Restored old reader/highlight/new-word colors, slider primary color, date picker treatment and user manual text/link/surface colors through current Sass and Vuetify theme tokens.
- Fixed dashboard daily goal card alignment, sidebar language icon alignment, chapter read-count chips, reader settings help-icon spacing, slider hover sizing and reader toolbar width regressions.

## Changed

- Kept current Vue 3 / Vuetify 3 component APIs and Sass module setup; no deprecated Vuetify 2 selectors were reintroduced as implementation dependencies.
- Added this release note with GHCR Docker update instructions.

## Docker image

Published images are built by GitHub Actions and pushed to GitHub Container Registry:

- `ghcr.io/kscop-n1/linguacafe-webserver:v0.5.38`
- `ghcr.io/kscop-n1/linguacafe-python-service:v0.5.38`
- `ghcr.io/kscop-n1/linguacafe-webserver:latest`
- `ghcr.io/kscop-n1/linguacafe-python-service:latest`

To update a Docker Compose install that already uses these GHCR images:

```bash
cd /home/serhii/docker/linguacafe
docker compose pull
docker compose up -d
```

If the compose file pins a version tag, update the image tags to `v0.5.38` first, then run the commands above.
