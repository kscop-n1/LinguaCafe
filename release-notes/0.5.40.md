# LinguaCafe 0.5.40

This release fixes confirmed Vue 3 / Vuetify 3 migration regressions found during the June 5 root-cause audit and expands the migration validation layer so similar residue is visible before release.

## Fixed

- Fixed the language selection dialog by migrating the custom dialog model contract from Vue 2 `value` / `input` to Vue 3 `modelValue` / `update:modelValue`.
- Fixed sidebar language flag and navigation icon rendering by moving list item media into Vuetify 3 `#prepend` slots.
- Fixed vocabulary pagination by replacing the legacy pagination input event with Vuetify 3 model update handling.
- Fixed admin dictionary, user, font type, book, and reader data table headers to use Vuetify 3 `title` / `key` header objects.
- Fixed confirmed app-owned invalid CSS declarations reported by browser tooling in text styling, vocabulary search, and cursor rules.

## Changed

- Split migration validation into hard blockers and review warnings:
  - `npm run check:legacy:hard`
  - `npm run audit:migration:review`
  - `npm run check:migration`
- Classified the 163 migration review candidates from the current audit instead of mass-rewriting broad false positives.
- Left non-word token behavior and other unproven reports as product logic backlog rather than migration fixes.

## Docker image

Published images are built by GitHub Actions and pushed to GitHub Container Registry:

- `ghcr.io/kscop-n1/linguacafe-webserver:v0.5.40`
- `ghcr.io/kscop-n1/linguacafe-python-service:v0.5.40`
- `ghcr.io/kscop-n1/linguacafe-webserver:latest`
- `ghcr.io/kscop-n1/linguacafe-python-service:latest`

To update a Docker Compose install that already uses these GHCR images:

```bash
cd /home/serhii/docker/linguacafe
docker compose pull
docker compose up -d
```

If the compose file pins a version tag, update the image tags to `v0.5.40` first, then run the commands above.
