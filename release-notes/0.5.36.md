# LinguaCafe 0.5.36

This release finishes another migration cleanup pass on the user theme settings page and extends the static audit so the same class of issue is caught earlier.

## Fixed

- Fixed the remaining Vuetify 2 form-control bindings on the user theme text styling settings page.
- Restored live preview updates for text styling sliders, checkboxes, selects and color pickers after the Vue/Vuetify migration.

## Changed

- Expanded the legacy migration check to catch old Vuetify value, input and change bindings on form controls.

## Validation

- Verified `npm run check:legacy` passes with no known Vue 2, Vuetify 2 or Laravel Mix source patterns.
