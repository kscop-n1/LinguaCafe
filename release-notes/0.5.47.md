# LinguaCafe 0.5.47

## Fixed

- Fixed reader token processing for hyphenated words split by the tokenizer, so words such as `stir-crazy`, `well-known`, `mother-in-law`, and `state-of-the-art` stay selectable as one vocabulary item.
- Fixed phrase selection and phrase indexing for phrases containing hyphenated words, including `go stir-crazy`.
- Kept invalid symbol, signed-number, arithmetic, dice-notation, and standalone possessive tokens out of vocabulary and phrase creation.
- Fixed dark-theme primary chips so Phrase edit modal metadata labels use the theme `on-primary` text color instead of becoming unreadable on the brown primary background.

## Docker

- Kept the Docker image size/build-cache updates in this release: workflow cache reuse for PHP and Python image builds, a smaller PHP runtime image path, and `.dockerignore` exclusions for local-only files and reports.
