# LinguaCafe 0.5.45

This release fixes the Library book details Chapters table regression introduced by the Vuetify 3 table migration and chapter-list pagination changes.

## Fixed

- Fixed the Chapters table footer total by switching migrated server-side chapter tables from the removed Vuetify 2 server-items-length/footer-props contract to Vuetify 3 v-data-table-server, items-length, and direct items-per-page-options props.
- Fixed the All page-size option. The frontend now sends the explicit all=true API contract instead of Vuetify's -1 page-size sentinel, so the backend no longer rejects the request with perPage validation errors.
- Fixed chapter totals becoming equal to the current page size. The table now uses backend paginator metadata for the total count and keeps that total stable across 10, 25, 50, and All.
- Fixed chapter statistics missing beyond the first large page by returning batch-calculated word counts with the chapter-list response for every returned chapter row, including rows after index 50.
- Fixed zero-value statistics rendering. Legitimate zero totals display as 0; missing stats for processed chapters are shown as unavailable instead of silently becoming blank.
- Fixed misleading empty states. Chapter API failures now preserve the previous valid table data and show a controlled error instead of clearing rows and showing No data available.
- Hardened stale request handling for chapter-list loads so older responses cannot overwrite a newer selected book or page-size request.
- Improved page-size dropdown anchoring by scoping footer select menu defaults to connected bottom placement with reposition-on-scroll behavior.
- Applied the same server-table pagination contract to the reader chapter picker, which shares the /chapters endpoint.

## API Contract

- /chapters continues to accept page and perPage for paginated requests, with perPage validated from 1 to 100.
- /chapters now accepts all=true to intentionally request every chapter for the selected book.
- Invalid page sizes such as perPage=-1 remain validation errors.
- Chapter-list responses include chapters, currentPage, lastPage, perPage, total, and complete wordCount values for processed returned chapters.

## Regression Coverage

- Added an 83-chapter backend regression test that verifies stable totals for 10, 25, 50, page 2, and All; validates the invalid perPage=-1 error path; and checks statistics after chapter 50.
- Updated the chapter word-count endpoint test to assert real statistics rather than old placeholder values.
- Added a static Vue migration guard that fails if server-side data tables use the removed server-items-length or data-table footer-props contracts again.

## Validation

- ./vendor/bin/phpunit --filter 'ChapterTest|VueMigrationStaticTest' passed in the dev webserver container: 11 tests, 64 assertions.
- npm run production passed and rebuilt the production bundle successfully.
- npm run check:migration passed.
