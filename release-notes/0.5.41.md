# LinguaCafe 0.5.41

This release fixes additional desktop and tablet UI regressions reported from annotated screenshots. The changes focus on reusable layout and component styling instead of screenshot-specific positioning.

## Fixed

- Aligned language selection modal items so each language renders as a consistent flag-and-label row inside a responsive grid.
- Aligned the sidebar bottom Language item with the Hide and Theme controls, including stable flag sizing in full and rail drawer modes.
- Restored a clear active state for Admin settings tabs so the selected section is visible in light and dark themes.
- Matched Installable languages flag sizing and table alignment with the dictionary language flag presentation.
- Removed the unnecessary internal scrollbar from the Edit daily goal dialog on desktop-sized viewports.
- Reduced Calendar day popover action buttons to compact circular icon buttons.
- Expanded the Book chapters table container and compacted chapter action buttons to reduce wasted side whitespace and accidental horizontal overflow.
- Restored circular Reader side-toolbar buttons with fixed equal width and height for all toolbar actions.

## Changed

- Kept the fixes scoped to reusable components and Sass modules: language selector, sidebar navigation, admin tabs/language table, home calendar/dialog controls, book chapters table, and reader toolbar.
- Left existing CSS override debt warnings as review-only warnings; this release only changes the UI regressions listed above.

## Docker image

Published images are built by GitHub Actions and pushed to GitHub Container Registry:

- `ghcr.io/kscop-n1/linguacafe-webserver:v0.5.41`
- `ghcr.io/kscop-n1/linguacafe-python-service:v0.5.41`
- `ghcr.io/kscop-n1/linguacafe-webserver:latest`
- `ghcr.io/kscop-n1/linguacafe-python-service:latest`

To update a Docker Compose install that already uses these GHCR images:

```bash
cd /home/serhii/docker/linguacafe
docker compose pull
docker compose up -d
```

If the compose file pins a version tag, update the image tags to `v0.5.41` first, then run the commands above.
